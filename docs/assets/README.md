# Documentation assets

Store repository-facing diagrams, screenshots, and short demonstrations here.
These files explain the project and are not Flutter runtime assets.

## Rules

- Never declare this directory in a Flutter pubspec.
- Prefer SVG for diagrams and optimized WebP or PNG for screenshots.
- Use descriptive lowercase filenames and meaningful Markdown alt text.
- Keep demonstrations short and reasonably sized for GitHub visitors.
- Do not include credentials, private dashboards, personal information, or
  internal tooling screenshots.
